## 1. 业务背景

- **主营业务**：中港两地牌代办 + 香港进口车销售 + 配套（验车、选号、合同、质保、车险）。
- **关键澄清：只做粤 Z 两地牌（港车北上方向），不做大陆 FV/FU 两地牌。**
- **车型**：埃尔法（Alphard）30/40 系、RX300、Tesla Model 3 等香港进口车。
- **口岸**：
  - 可办理/热门：深圳湾、莲塘、沙头角、港珠澳大桥。
  - **皇岗、文锦渡：已长期停批，市面上现牌炒作至上百万，仅作信息补充/谈资，不写成可办理。**
- **客单价**：办一张牌数十万级（文案中**不得出现价格与具体数字**，只体现价值）。

## 2. 客户群体

- 主要是**香港人 / 持香港身份证者**，以及有两地通行、两地商务需求的大陆客户。
- 高净值人群，重**价值、合规风险、服务售后**；车辆（如埃尔法）带**面子**属性。
- 大量客户习惯**粤语**沟通。

## 3. 内容场景

| 场景 | 说明 |
|---|---|
| 业务动态/晒单 | 到店、落定、验车、选号、装卡通关、交车。**晒单是"环节已完成"的通知（完成态），非进行时。** |
| 车源推介 | 车型/年份/配置，精炼高级 |
| 知识科普 | 两地牌方向、口岸、术语等 |
| 早安（周一~周五） | 开头固定「早晨，星期X。」，景物/心境 → 双城寓意，弱销售 |
| 节日 | 中秋、国庆等；人文情怀，仅带 IP；**不涉政治人物** |
| 日常/公司事 | 团队、聚餐、收工、休闲等 |

**配图规则**：
- 群聊截图（如「恭喜」类）→ 信息明确，**仅提供图片，无文字描述**。
- 交车、今日推荐车型等 → **配图 + 一段文字说明**。
- **永不只有纯文案，一定配图。**

## 4. 风格要求（核心）

- 基调：**高级、克制、简洁、留白、举重若轻**；粤港商务质感。
- 反感：微商味、廉价促销、口水话、公文腔、网红腔、千篇一律模板。
- 语言：**繁体中文，香港粤语书写可接受**；分行短句，适合朋友圈阅读。
- **品牌不固定人设**：只有统一调性，内容随场景游走（牌 / 车 / 公司 / 科普 / 日常）。
- 收尾落款：**`#明哥中港牌`**（带井号，单独成行作署名，非普通话题标签堆砌）。

### 第一原则：**"不说满"**
- 旧方案的病根：总想「讲完 + 升华 + 感谢」→ 太满、太俗。
- 高级感 = **只给一个切面，不升华，把感受留给读者。**

## 5. 硬性规则（质检一票否决项）

1. 结尾必含 **`#明哥中港牌`**。
2. **无任何具体数字**：成交价、车牌号、里程等一律不出现。
3. 早安 / 节日文案**禁止硬广**（不推车、不推牌套餐）。
4. 繁体中文、分行排版。
5. **不涉政治敏感事件、不出现政治人物**。谈资类只用模糊表述（如「有小道消息」「某渠道消息」）。
6. 晒单统一为**完成态**通知。
7. 皇岗 / 文锦渡**不得写成可办理**。

## 6. Agent 能力清单（架构）

### 6.1 真 Agent 的四标志
工具使用 · 记忆系统 · 自主循环 · 反思优化。旧方案（单提示词）四点全缺，故质量无保障。

### 6.2 能力分层

**A. 感知层**
- 多模态输入：纯图 / 纯文 / 图文 / 纯需求（如「今晚帶隊去深圳聚餐」「寫個中秋文案」）。
- 视觉 + OCR：群聊截图提取已完成状态、口岸、车型、客户动作；车图识别车型/颜色/场景。
- 意图识别 + 场景路由（第 3 节六类场景）。
- 要素结构化：口岸·车型·动作·情绪·可否带业务。
- **信息缺口检测 + 主动追问（必须实现）。**

**B. 记忆层**（根治"越写越像"）
- 品牌语气资产库（tone DNA：好样本 + 调性规则 + 句法偏好）。
- 历史文案库 + 相似度指纹（去重）。
- 事实知识库（RAG：粤Z政策、口岸、车型、皇岗/文锦渡停批、术语口径）。
- 套话黑名单（拦截「感恩託付／圓滿收官／資深粉絲／隨時等候每一位」等）。
- 反馈记忆（用户选中哪版、改了哪里）。
- **轮换记账**（记住上次用的叙事角度/结构，下次强制换）。

**C. 决策层**
- 场景路由与策略选择。
- **叙事角度/结构轮换调度**：细节特写 / 群聊引用 / 时间场景 / 专业门道 / 对比 / 立场 / 轻哲思。
- 决定语言浓度、版本数、是否给配图建议。
- 工具调度（是否 OCR、是否联网查资料）。

**D. 生成层**
- 多候选同生成；三档语气：**沉稳质感 / 简约克制 / 极简留白**。
- 香港粤语书写、繁体、分行；图文呼应 + 配图方向建议。

**E. 质检层**（决定质量下限，最易被忽略）
- 硬规则校验（第 5 节，一票否决）。
- 软评分：高级感·新意·调性 —— **评审器与生成器解耦**（避免自卖自夸）。
- 去重检测：向量相似度比对历史。
- 事实校验：口岸可办性、方向对不对。
- 反思改写循环（设最大轮次）。

**F. 输出层**
- 三版文案 + 配图建议，供选；一键复制。

**G. 学习层**
- 用户选择/编辑回填 → 定期更新语气库与黑名单。

### 6.3 典型输入 → 输出
```
① 纯图（群聊截图）
   OCR→识别"選號完成/口岸/車型" → 场景=晒单 → 选角度 → 生成 → 校验(完成态·无数字·落款) → 3版
② 图文（交车：图 + "今日交咗部40系埃爾法畀陳生"）
   图证车型场景 + 文补细节 → 场景=交车 → 生成 → 校验 → 3版
③ 纯需求（"今晚收工帶隊去深圳食飯"）
   无图 → 场景=日常 → 判断信息是否足够 → 够则生成，不够则追问 → 3版
```

## 7. 定时情报线（谈资，非内容发布）

**需求**：每隔一周或更频繁，自动搜索与业务相关的行业资讯，**仅作参考/谈资/分享，不作为明确信息发布**。

**范围**：主营业务相关及周边，如口岸动态、港车/车市行情（主攻香港市场）、两地牌政策、税务合规等。

**两条信息处理原则**：
1. **源头上核实**：白名单域名 + 多源交叉验证（2+ 独立来源一致才记为"事实"）；保留原始链接。
2. **分享不用肯定语气**：可用调侃、引用；**不添加具体/敏感来源**，用「有小道消息」「某渠道消息」等模糊表述。

**流程**：
```
Cron 定时唤醒
  → 抓取：白名单 RSS/站点 + 搜索 API 补充
  → 核实：白名单过滤 + 多源交叉 + 标注来源
  → 归档：写入「资讯库」，与已推送去重
  → 产出：① 内部摘要（带链接） ② 3 版"谈资型"朋友圈草稿（调侃/引用语气）
  → 用户挑选后才发（**永不自动发布**）
```

## 8. 搜索方案（免费渠道，全部可用尽用）

**前提**：服务器为香港服务器，有稳定外网，无出口限制。

| 方案 | 免费额度 | 是否需注册/绑卡 | 特点 |
|---|---|---|---|
| **Tavily** | 1,000 次/月（另有 keyless 限速模式） | 否 | 专为 LLM 设计，直接返回干净正文，**首选** |
| **Firecrawl（keyless）** | 1,000 次/月 | 否（零配置） | 无需注册无需 Key，**兜底** |
| **SearXNG（开源自建）** | 无限（自托管） | 否 | 元搜索聚合 261+ 引擎，免费 JSON API；缺点是上游会限流/验证码，需维护 |
| **Exa** | 注册送额度 + 每月额度 | 否 | 语义/相似检索强 |
| **Diffbot** | 10,000 次/月 | 否 | 额度大，偏实体/知识图谱 |
| **You.com（MCP 免费端点）** | 100 次/天 | 否 | 零注册可用 |
| Brave Search API | 新用户改 $5/月额度 | 是（需绑卡） | 独立索引，新用户已非纯免费 |

**建议组合**：
- 主：**Tavily**（省心，1,000/月对每周 1~2 次完全够用）。
- 辅：**Firecrawl keyless / SearXNG 自建**（零配置 + 无限兜底），叠加中文 RSS 定向源。
- **重要判断**：本地化行业资讯（香港/中文长尾）通用搜索引擎覆盖不一定好，**「白名单站点 + RSS 定向抓取」为主、搜索 API 为辅**更稳、更省、更可控。
- 注意：SearXNG 仅供自建实例用于 Agent，勿指向公共实例（会拖垮志愿者基础设施）。

## 9. 技术栈选型

| 组件 | 选择 |
|---|---|
| 部署 | 香港服务器（有外网） |
| LLM | **DeepSeek V4.1 Flash**（多模态），走官方 API，**不自部署模型** |
| 编排 | **轻量**，不上重框架（功能不多）；最简 function-calling 循环即可 |
| 搜索/抓取 | Tavily + Firecrawl keyless + SearXNG + RSS（见第 8 节） |
| 定时 | cron / APScheduler |
| 向量库（去重/RAG） | Chroma / sqlite-vec（本地免费） |
| 前端 | 网页聊天版（基础版先做这个） |

## 11. 防重复机制（"越写越像"的根治）

1. **叙事角度库**轮换：细节特写 / 群聊引用 / 时间场景 / 专业门道 / 对比 / 立场 / 轻哲思。系统记账，强制换。
2. **结构轮换**：开头（画面/引用/设问/时间）× 结尾（动作定格/一句留白/署名）。
3. **相似度指纹去重**：与近 N 条比对，超阈值自动重写。
4. **套话黑名单**：`感恩…託付`、`圓滿收官`、`每一份成交`、`誠摯…`、`隨時等候每一位` 等。
5. **金句配额**：多数平实收尾，偶尔点睛——句句升华反而腻。
6. **落款规范化**：`#明哥中港牌` 作署名单独成行。
